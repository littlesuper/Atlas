## 一句话范围

**做**：在 Atlas **已有的**依赖调度器与风险检测之上，包一层"听懂人话（意图解析）+ 算影响（复用调度器干跑）+ 暴露风险（确定性判定撞节点）+ 说人话（结果叙述）+ 预览确认（人工闸门）"的薄壳。

**不做**：不重建调度器/风险引擎；不自动应用；不做跨项目资源调度；不做工期/延期概率预测；不碰排期以外的实体。详见 `01` §出范围。

## 给人（L.S.）的提示

- 本包对现有调度器/风险引擎的内部接口是**契约级假设**，不是已核实的事实。Claude Code 的 step-0 就是去核对这些假设。**若它报告"现有调度器无法干跑"或"风险引擎只能评估已落库排期"，请在它继续前看一眼它给的方案**——这是本灯塔的设计分水岭（见 `01` §关键集成问题）。
- 沿用你一贯的节奏：让 Claude Code 分步执行、每步 check-in、动数据库/迁移前必须停下来等你确认。
