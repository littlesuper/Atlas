## 给 L.S. 的使用说明

1. **放置文档**：把 `atlas-ai-scheduling-beacon/` 整个目录拷进 Atlas 仓库（建议 `docs/specs/ai-scheduling-beacon/`），让 Claude Code 能读到。
2. **第一个回合只会得到"验证简报"**：这是有意设计的闸门。重点看它对问题一（调度器能否干跑）的结论——这决定了工作量。确认无误再放行。
3. **按你的节奏**：每个 check-in 都可以叫停、修方向。涉及调度器重构和数据库迁移的两个点，它会主动停下等你。
4. **若你更想让我先看真实代码**：也可以把 step-0 要核实的那几个文件（schema.prisma、调度器、dependencyValidator.ts、风险引擎、circuitBreaker.ts）贴给我，我把规格里的"契约假设"替换成真实接口，再让 Claude Code 跳过部分 step-0 直接实现。两条路都行。
