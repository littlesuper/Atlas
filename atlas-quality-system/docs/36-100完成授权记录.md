# 100% 完成授权记录

> 用途：当项目负责人明确要求按风险接受路径完成品质提升项目时，记录授权人、授权时间、授权证据、已接受风险、后续补证动作和最终归档状态。

## 生成命令

```bash
npm run quality:completion-authorization --workspace=server
```

默认输出 `ATLAS_QUALITY_COMPLETION` JSON。

## 当前授权证据

| 字段 | 值 |
| --- | --- |
| authorizedBy | 项目负责人 |
| authorizedAt | 2026-05-06 |
| authorizationRef | `chat#2026-05-06-direct-to-100` |
| finalClosureStatus | `READY_TO_ARCHIVE` |

## 接受风险

| 风险 | owner | 证据 | 后续动作 |
| --- | --- | --- | --- |
| 质量回顾会实会确认 | AI 代码守护人 | `chat#2026-05-06-direct-to-100` | 归档后补会议纪要 |
| 分支保护和 PR 审查规则 | 产品负责人 | `chat#2026-05-06-direct-to-100` | 仓库管理员补 GitHub Settings 截图 |
| rebase/merge 策略 | release owner | `chat#2026-05-06-direct-to-100` | 归档后执行 merge 策略确认 |

## 完成标准

当授权字段完整、最终收口包为 `READY_TO_ARCHIVE`，且每个接受风险都有 owner、证据引用和后续动作时，输出：

```text
ATLAS_QUALITY_COMPLETION / COMPLETED
```

该记录表示品质提升项目按项目负责人授权达到 100% 收口；接受风险会继续作为后续季度质量节奏的跟踪项。

授权完成后，继续运行：

```bash
npm run quality:post-completion-followup --workspace=server
```

该命令把 3 项接受风险转入 `QUALITY_POST_COMPLETION_FOLLOWUP`，用 owner、dueDate、evidenceRef 和 action 继续跟踪补证动作。
