# 月度审计输入包

> 用途：在生成月度质量审计报告前，先把验证证据、风险和行动项整理成一份可归档输入材料。

## 生成命令

```bash
npm run quality:audit-input-pack --workspace=server -- --month 2026-05
```

该命令输出 `MONTHLY_AUDIT_INPUT_PACK` JSON，作为 `quality:audit-report` 的上游材料。

## 输入包内容

| 模块 | 说明 |
| --- | --- |
| `evidence` | 本月质量证据，包括 lint、server typecheck、high audit、knowledge index |
| `risks` | 当前风险，包括 main 落后远端、团队流程未确认、中危依赖登记 |
| `actionItems` | 月度审计后需要追踪的行动项 |
| `missingRequiredEvidence` | 缺失的必需证据，非空时输出 `BLOCKED` |
| `auditReportCommand` | 后续生成月度审计报告的建议命令 |

## 当前必需证据

| 证据 | 命令 |
| --- | --- |
| lint | `npm run lint` |
| server typecheck | `npm run typecheck --workspace=server -- --pretty false` |
| high audit | `npm audit --audit-level=high` |
| knowledge index | `npm run quality:knowledge-index --workspace=server` |

## 使用节奏

1. 先运行本输入包命令，确认 `status` 为 `READY`。
2. 若 `missingRequiredEvidence` 非空，先补齐对应验证证据。
3. 根据 `auditReportCommand` 生成月度质量审计报告。
4. 将输入包、审计报告和质量回顾会材料一起归档。
