# 质量知识库导航

> 用途：作为 Atlas 质量体系的入口页，帮助不同角色快速找到方案、清单、命令型报告和 Week 8 收口材料。

## 生成索引

```bash
npm run quality:knowledge-index --workspace=server
```

该命令输出 `QUALITY_KNOWLEDGE_INDEX` JSON，并检查关键路径是否已纳入知识库索引。

## 维护规则

1. 新增质量文档时，同时更新 `quality:knowledge-index` 预置索引。
2. 新增命令型报告时，同时补充本导航的“命令型资产”表。
3. 每次 Week 8 进度更新后，同步 `PROJECT_PROGRESS.md`。
4. `missingRequiredPathCount` 不为 0 时，不应认为知识库整理完成。
