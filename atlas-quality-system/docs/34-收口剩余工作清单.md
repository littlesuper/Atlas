# 收口剩余工作清单

> 用途：把 `quality:closure-gate` 中仍未 ready 的项目收敛成一份 owner、证据要求和下一步命令清单。它只展示最后 1% 的剩余执行项，不替代真实会议、仓库设置或人工确认。

## 生成命令

```bash
npm run quality:closure-remaining-work --workspace=server
```

默认输出 `QUALITY_CLOSURE_REMAINING_WORK` JSON。

## 当前剩余项

| 项目 | 状态 | Owner | 证据要求 | 下一步命令 |
| --- | --- | --- | --- | --- |
| monthly audit run | `ACTION_REQUIRED` | AI 代码守护人 | `MONTHLY_AUDIT_RUN / ACTION_REQUIRED` 并附带回顾会决策 | `quality:audit-run` |
| quality action tracker | `ACTION_REQUIRED` | AI 代码守护人 | `QUALITY_ACTION_TRACKER` 中 open action 已分派或接受 | `quality:action-tracker` |
| blocker resolution | `ACTION_REQUIRED` | AI 代码守护人 | `QUALITY_BLOCKER_RESOLUTION / RESOLVED` | `quality:blocker-resolution` |
| evidence intake | `ACTION_REQUIRED` | AI 代码守护人 | `QUALITY_EVIDENCE_INTAKE / READY_TO_CONFIRM` | `quality:evidence-intake -- --confirm "..."` |

## 完成标准

当 `remainingGateChecks` 为 0 时，输出：

```text
QUALITY_CLOSURE_REMAINING_WORK / READY
```

如果存在 `BLOCKED` 项，输出 `BLOCKED`；否则只要仍有未 ready 项，输出 `ACTION_REQUIRED`。
