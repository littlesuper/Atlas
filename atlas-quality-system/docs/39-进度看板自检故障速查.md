# 进度看板自检故障速查

> 用途：当 `quality:progress-guard` 输出 `BLOCKED` 时，按 gap 消息快速定位修复动作。

## 速查表

### 输入校验类

| gap 消息 | 原因 | 修复动作 |
| --- | --- | --- |
| `progress board input is invalid` | 程序化调用传入非对象或数组 | 检查调用方，确保传入普通对象 `{ content, requiredDate, ... }` |
| `progress board content is invalid` | `content` 参数不是字符串 | 确认 `content` 为 `string` 类型 |
| `progress board generatedAt is invalid` | `generatedAt` 不是合法 `Date` | 确认传入 `new Date()` 或有效 `Date` 实例 |
| `verification evidence markers are invalid` | `requiredEvidenceMarkers` 不是数组 | 改为字符串数组，如 `['marker1']` |
| `verification evidence marker is invalid` | 数组中混入非字符串 marker | 移除非字符串项 |
| `changelog markers are invalid` | `requiredChangelogMarkers` 不是数组 | 同上 |
| `changelog marker is invalid` | 同上 | 同上 |

### 日期类

| gap 消息 | 原因 | 修复动作 |
| --- | --- | --- |
| `progress board required date is invalid` | CLI `--date` 参数非字符串 | 传入 `YYYY-MM-DD` 格式字符串 |
| `progress board required date is blank` | CLI `--date` 参数为空或纯空白 | 传入有效日期值 |
| `progress board required date format is invalid: <值>` | 日期格式非 `YYYY-MM-DD`（如 `2026/05/06`） | 改为 `2026-05-06` |
| `progress board required date value is invalid: <值>` | 日期格式正确但日历不存在（如 `2026-13-40`） | 改为真实日历日期 |
| `progress board date line is missing` | `## 1. 总览` 中没有 `**当前日期**：YYYY-MM-DD` 行 | 在总览区块添加 `**当前日期**：2026-05-08` |
| `progress board date value is missing` | 日期标签存在但冒号后为空 | 补写日期值 |
| `progress board date line is duplicated` | 总览中出现多条当前日期标签行 | 合并为一条 |
| `progress board date format is invalid: <值>` | 看板中日期值格式错误 | 改为 `YYYY-MM-DD` |
| `progress board date value is invalid: <值>` | 看板中日期日历值不存在 | 改为真实日历日期 |
| `progress board date is not updated: <旧日期>` | 看板日期 ≠ requiredDate | 更新看板 `**当前日期**` 为当天日期 |

### Week 8 进度类

| gap 消息 | 原因 | 修复动作 |
| --- | --- | --- |
| `Week 8 required progress threshold is invalid: <值>` | `--min-week8-progress` 不是 0-100 整数 | 传入合法整数，如 `99` 或 `100` |
| `Week 8 required progress threshold is invalid: non-number` | `--min-week8-progress` 传入非数字 | 改为数字 |
| `Week 8 progress line is missing` | 总览中没有 `Week 8 [####...] NN%` 行 | 在总览区块添加标准进度行 |
| `Week 8 progress line is duplicated` | 总览出现多条 Week 8 进度行 | 合并为一条 |
| `Week 8 progress value is missing` | 进度行缺少百分比（如缺少空格或 `%` 后有非空白字符） | 确保格式为 `Week 8 [####################] 100%` |
| `Week 8 progress bar is missing` | 进度条为空 | 补齐 20 位进度条 |
| `Week 8 progress bar is invalid` | 进度条含非法字符（非 `#`/`-`） | 只使用 `#`（已完成）和 `-`（未完成） |
| `Week 8 progress bar length is invalid: <长度>` | 进度条长度 ≠ 20 | 调整为 20 字符（10 `#` = 50%） |
| `Week 8 progress value is invalid: <值>` | 进度值非 0-100 整数（如 `099`、`-1`、`101`、`99.5`） | 改为合法整数 |

### 看板结构类

| gap 消息 | 原因 | 修复动作 |
| --- | --- | --- |
| `progress board overview section is missing` | 缺少 `## 1. 总览` | 添加该标题 |
| `progress board overview section boundary is missing` | 总览后缺少 `## 2.` 后续标题 | 确保章节结构完整 |
| `progress board verification evidence section is missing` | 缺少 `## 5. 最近验证证据` | 添加该标题 |
| `progress board verification evidence section is duplicated` | `## 5.` 出现多次 | 合并或删除重复标题 |
| `progress board next execution section is missing` | 缺少 `## 6. 下一步执行顺序` | 添加该标题 |
| `progress board next execution section boundary is missing` | `## 6.` 后缺少 `## 7.` | 确保章节结构完整 |
| `progress board changelog section is missing` | 缺少 `## 7. 变更日志` | 添加该标题 |
| `progress board changelog section is duplicated` | `## 7.` 出现多次 | 合并或删除重复标题 |

### 证据与变更日志类

| gap 消息 | 原因 | 修复动作 |
| --- | --- | --- |
| `verification evidence marker is missing: <marker>` | `## 5.` 当天没有包含该 marker 的 PASS 行 | 添加包含该 marker 的验证证据行 |
| `changelog marker is missing: <marker>` | `## 7.` 当天没有包含该 marker 的变更日志行 | 添加包含该 marker 的变更日志行 |

## 证据行不被计数的常见原因

即使添加了 PASS 行，仍可能因以下原因不被计数：

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 行有 marker 但未被匹配 | 日期列 ≠ requiredDate 当天 | 确保第一列为当天 `YYYY-MM-DD` |
| 日期正确但仍不匹配 | 结果列不是 `PASS` | 确保第 3 列为 `PASS`（大小写不敏感） |
| `EXPECTED_FAIL` 行不算通过 | `EXPECTED_FAIL` 只记红灯，不算完成 | 另外添加 `PASS` 证据行 |
| 命令列是占位值 | 命令列为 `-`/`N/A`/`NONE` 等 | 替换为真实可复制命令 |
| 说明列是占位值 | 说明列为 `TBD`/`TODO`/`PENDING` 等 | 替换为真实说明文字 |
| 命令未用 inline code | 命令列未用反引号包裹 | 用 `` `command` `` 包裹命令 |
| inline code 内是占位值 | `` `-` `` 或 `` `N/A` `` | 替换为真实命令 |
| 多反引号 inline code 不被识别 | 旧版只支持单反引号 `` `cmd` `` | 已修复：`` ``cmd`` `` 等多反引号写法也可识别 |

## 变更日志行不被计数的常见原因

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 行有 marker 但未被匹配 | 日期列 ≠ requiredDate 当天 | 确保第一列为当天 `YYYY-MM-DD` |
| 缺少进度影响列 | 行只有 2 列（日期 + 完成事项） | 补齐第 3 列进度影响说明 |
| 完成事项列是占位值 | 完成事项为 `-`/`N/A`/`NONE` 等 | 替换为真实变更描述 |
| 进度影响列是占位值 | 进度影响为 `TBD`/`TODO`/`PENDING` 等 | 替换为真实进度影响说明 |
