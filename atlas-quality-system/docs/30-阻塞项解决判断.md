# 阻塞项解决判断

> 用途：统一判断 Week 8 阻塞项是否已经解决。解决路径有两种：实际清除，或由团队带证据接受风险。

## 默认命令

```bash
npm run quality:blocker-resolution --workspace=server
```

默认输入为：

| 来源 | 默认状态 |
| --- | --- |
| `QUALITY_BLOCKER_REGISTER` | `ACTION_REQUIRED` |
| `QUALITY_BLOCKER_ACCEPTANCE` | `ACTION_REQUIRED` |

因此默认输出 `QUALITY_BLOCKER_RESOLUTION / ACTION_REQUIRED`。

## 阻塞已清除

```bash
npm run quality:blocker-resolution --workspace=server -- \
  --blocker-register-status CLEAR \
  --blocker-acceptance-status ACTION_REQUIRED
```

输出 `RESOLVED`，`resolutionPath` 为 `CLEARED`。

## 阻塞被接受

```bash
npm run quality:blocker-resolution --workspace=server -- \
  --blocker-register-status ACTION_REQUIRED \
  --blocker-acceptance-status ACCEPTED
```

输出 `RESOLVED`，`resolutionPath` 为 `ACCEPTED`。

## 下一步

阻塞解决后，进入：

```bash
npm run quality:evidence-intake --workspace=server -- --confirm ...
```

如果仍为 `ACTION_REQUIRED`，先补充 `quality:blocker-acceptance` 或实际清除阻塞项。
