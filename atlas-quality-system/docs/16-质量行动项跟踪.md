# 质量行动项跟踪

> 用途：把月度审计和质量回顾会产生的建议，转成有 owner、截止日期和阻塞原因的行动项列表。

## 生成命令

```bash
npm run quality:action-tracker --workspace=server
```

该命令输出 `QUALITY_ACTION_TRACKER` JSON：

- `DONE`：所有行动项已完成。
- `ACTION_REQUIRED`：存在 open 或 blocked 行动项。
- `BLOCKED`：行动项缺 owner 或截止日期。

## 阻塞项

| 行动项 | 阻塞原因 |
| --- | --- |
| 确认分支保护和 PR 审查规则 | 需要仓库管理员权限 |

## 维护规则

1. 每次月度审计输出 `ACTION_REQUIRED` 时，同步更新行动项跟踪。
2. 每个行动项必须有 owner 和 dueDate。
3. 阻塞项必须写清楚阻塞原因。
4. 质量回顾会结束后，将会议结论回填到本跟踪表。
