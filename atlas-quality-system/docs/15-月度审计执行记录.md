# 月度审计执行记录

> 用途：把月度审计输入包和月度质量审计报告串起来，形成一次可归档的审计执行记录。

## 生成命令

```bash
npm run quality:audit-run --workspace=server -- --month 2026-05
```

该命令输出 `MONTHLY_AUDIT_RUN` JSON：

- 输入包 `READY` 时，生成嵌套的 `MONTHLY_QUALITY_AUDIT` 报告。
- 输入包 `BLOCKED` 时，不生成审计报告，并列出缺失证据。
- 当前存在真实风险时，输出 `ACTION_REQUIRED`，用于提醒后续闭环。
