# 收口请求包

> 用途：把 `quality:closure-remaining-work` 的待办项转成可直接发给 owner 的请求文本、证据要求和下一步命令。该包不替代人工确认，只负责把最后 1% 的人工输入变成可分发清单。

## 生成命令

```bash
npm run quality:closure-request-pack --workspace=server
```

默认输出 `QUALITY_CLOSURE_REQUEST_PACK` JSON。

## 默认请求项

| 请求项 | 证据要求 | 下一步 |
| --- | --- | --- |
| monthly audit run | `MONTHLY_AUDIT_RUN / ACTION_REQUIRED` 并附带回顾会决策 | `quality:audit-run` |
| quality action tracker | `QUALITY_ACTION_TRACKER` 中 open action 已分派或接受 | `quality:action-tracker` |
| blocker resolution | `QUALITY_BLOCKER_RESOLUTION / RESOLVED` | `quality:blocker-resolution` |
| evidence intake | `QUALITY_EVIDENCE_INTAKE / READY_TO_CONFIRM` | `quality:evidence-intake -- --confirm "..."` |

## 使用方式

1. 运行 `quality:closure-request-pack`。
2. 将每个 `requestText` 发给对应 owner。
3. owner 回填证据后，按 `nextCommands` 依次执行。
4. 再运行 `quality:closure-remaining-work` 和 `quality:closure-gate` 确认剩余项是否减少。

## 完成标准

当 `quality:closure-remaining-work` 已无剩余项时，请求包输出：

```text
QUALITY_CLOSURE_REQUEST_PACK / READY
```

只要仍有待 owner 回填的请求项，输出 `ACTION_REQUIRED`。
