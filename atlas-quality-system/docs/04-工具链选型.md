# Atlas 工具链选型

> 本文档列出每个测试维度的具体工具推荐和选型理由

## 一、技术栈假设

由于Atlas是Web应用,本文档**默认假设**使用以下技术栈(如果不同,可以让Claude帮助调整对应工具):

**前端**:
- TypeScript + React (或 Vue 3)
- Vite (构建工具)
- TailwindCSS (样式)

**后端**(三选一):
- Node.js + TypeScript + Express/Fastify/NestJS
- Python + FastAPI
- Go + Gin (如果性能要求高)

**数据库**:
- PostgreSQL(主推荐)
- 或MySQL

**部署**:
- Docker容器化
- Vercel/Netlify(前端) + Railway/Fly.io(后端) 入门首选
- 或自建K8s(成熟期)

## 二、核心工具清单

### 静态分析(代码层)

| 工具 | 用途 | 配置位置 | 成本 |
|------|------|---------|------|
| **ESLint** | JS/TS代码规范 | `.eslintrc.json` | 免费 |
| **Prettier** | 代码自动格式化 | `.prettierrc` | 免费 |
| **TypeScript** | 类型检查 | `tsconfig.json` | 免费 |
| **stylelint** | CSS规范 | `.stylelintrc.json` | 免费 |
| **ruff** | Python lint(快) | `pyproject.toml` | 免费 |

**推荐配置严格度**:
- TypeScript: `"strict": true`
- ESLint: 使用 `eslint:recommended` + `@typescript-eslint/strict`
- mypy: `--strict` 模式

### 安全扫描

| 工具 | 用途 | 频率 | 成本 |
|------|------|------|------|
| **CodeQL** | 代码安全分析(最强) | 每次PR | GitHub免费 |
| **Snyk** | 依赖漏洞扫描 | 每次PR + 每日 | 免费版够用 |
| **TruffleHog** | 密钥泄露检测 | 每次commit | 免费 |
| **detect-secrets** | 密钥扫描备选 | pre-commit | 免费 |
| **Bandit** | Python安全 | 每次PR | 免费 |
| **Semgrep** | 通用安全规则 | 每次PR | 免费版够用 |
| **OWASP ZAP** | DAST动态扫描 | 每次staging | 免费 |
| **Trivy** | 容器/依赖扫描 | 镜像构建时 | 免费 |
| **Dependabot** | 依赖自动更新 | 持续 | GitHub免费 |

**最低必备**(免费且强力):
- CodeQL + Snyk + TruffleHog + Dependabot

### 测试框架

#### 前端测试

| 测试类型 | 推荐工具 | 备选 |
|---------|---------|------|
| 单元测试 | **Vitest** | Jest |
| 组件测试 | **Playwright Component Testing** | React Testing Library |
| E2E测试 | **Playwright** | Cypress |
| 视觉回归 | **Chromatic** (有Storybook) | Percy |
| 可访问性 | **axe-playwright** | Pa11y |

**为什么选Playwright而非Cypress?**
- 多浏览器原生支持(Chrome/Firefox/Safari)
- 速度更快(并行能力强)
- API更现代(自动等待、locator API)
- 微软官方维护,持续投入

**为什么选Vitest而非Jest?**
- 启动速度快10倍以上
- 与Vite生态无缝集成
- API兼容Jest,迁移成本低


## 八、避坑指南

### ❌ 不要犯的错误

1. **同时引入太多工具**
   - 后果:消化不良,每个都用得很烂
   - 正确:按本文档的优先级,每周2-3个

2. **过度依赖付费工具**
   - 后果:成本失控,被工具绑定
   - 正确:免费工具够用就别升级,关键场景才付费

3. **追求最新最酷的工具**
   - 后果:文档少、坑多、找不到答案
   - 正确:选成熟主流方案

4. **工具配置后不维护**
   - 后果:逐渐失效,变成假的安全感
   - 正确:每月review一次配置

5. **用工具替代流程**
   - 后果:工具再好,人不按流程也白搭
   - 正确:工具+流程+文化三位一体
